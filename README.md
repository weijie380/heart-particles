# 3D Heart Particles ❤️

基于手势控制的 **3D 粒子爱心** 交互页面。摄像头识别人手，握拳/张手控制粒子聚散。

## 功能

- 🖐️ **手势控制**：握拳→爱心聚拢、张手→粒子散开、捏合→照片放大
- 🎨 **3D 爱心**：2000 个粒子组成立体心形，深红/玫瑰金/粉红配色
- 📸 **照片上传**：可上传照片嵌入粒子云中
- 🎵 **背景音乐**：支持上传自定义音乐
- 💻 **鼠标交互**：无摄像头也可点击切换状态

## 操作说明

| 手势 | 功能 |
|------|------|
| ✊ 握拳 | 粒子聚拢为爱心 |
| 🖐️ 张手 | 粒子散开漂浮 |
| 👌 指尖捏合 | 切换到照片放大 |
| 🖱️ 鼠标点击 | 切换状态（无摄像头时） |
